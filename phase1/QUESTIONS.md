# Problem Statement and Research Plan

## 1. What problem am I solving?

I am addressing the problem of **traditional coding assessment systems that mainly focus on checking whether submitted code produces the correct output, with limited personalized feedback and learning guidance**. The goal is to develop an **AI-Based Coding Assessment Platform** that can automatically evaluate programming skills, analyze students' code and problem-solving approaches, and provide personalized feedback to help them improve their coding abilities.

## 2. Why is this problem important?

This problem is important because **evaluating programming skills manually can be time-consuming and difficult, especially when a large number of students are involved**. Traditional coding platforms may provide test-case results or scores but may not always explain **why a solution is inefficient, how the code can be improved, or which programming skills the student needs to develop**.

Solving this problem can improve **assessment efficiency, feedback quality, learning personalization, and coding skill development** for students, teachers, and educational institutions.

## 3. What has already been done?

Several existing approaches and systems have been developed for online coding assessment. These include **online code editors, automated test-case evaluation, programming problem platforms, code execution systems, and AI-based coding assistance and feedback systems**.

Previous research and existing platforms have demonstrated that **automated code execution and test-case-based evaluation can reduce manual assessment effort and provide quick results to learners**. AI-based approaches can further support code analysis, explanations, hints, and personalized feedback.

## 4. What are the limitations of existing approaches?

Despite their effectiveness, existing coding assessment approaches have several limitations. These may include:

* Limited personalized feedback
* Mainly focusing on correct or incorrect output
* Limited analysis of individual coding skills
* Lack of adaptive difficulty based on student performance
* Limited guidance for improving weak areas
* Difficulty in understanding why a solution is inefficient
* Limited integration of assessment with personalized learning
* Possibility of students relying heavily on AI-generated solutions without understanding the code

Therefore, there is a need for an improved approach that can **combine automated coding assessment with AI-based code analysis, personalized feedback, adaptive assessments, and skill-based learning recommendations**.

## 5. What exactly will my system do?

The proposed **AI-Based Coding Assessment Platform** will provide an online environment where students can solve programming problems and receive automated and AI-assisted evaluation.

It will take **the student's programming code, problem-solving response, test-case results, and assessment performance** as input and process them using **automated code execution, test-case evaluation, performance analysis, and AI-based code analysis** to produce **scores, detailed feedback, code explanations, hints, skill analysis, and personalized learning recommendations**.

### Main Objectives

* **Automatically evaluate programming solutions using test cases and coding criteria.**
* **Use AI to analyze student code and provide meaningful feedback, explanations, and improvement suggestions.**
* **Adapt question difficulty according to the student's performance and skill level.**
* **Identify strengths and weaknesses and provide personalized learning recommendations.**

The system will be designed to address the key limitations identified in existing approaches while providing **a more personalized, intelligent, and student-focused coding assessment experience**.

## 6. How will I evaluate whether my solution is better or useful?

The proposed system will be evaluated using appropriate **performance, efficiency, accuracy, and usability metrics**.

The evaluation may include:

* **Test-case Accuracy** – to measure whether submitted programs correctly solve the given problems.
* **Code Evaluation Performance** – to measure the correctness and reliability of automated assessment.
* **AI Feedback Quality** – to evaluate whether the generated feedback is relevant, understandable, and useful.
* **Processing Time / Latency** – to determine how quickly code evaluation and AI feedback are generated.
* **Skill Analysis Accuracy** – to check whether the system can correctly identify students' strengths and weaknesses.
* **Comparison with Existing Approaches** – to determine whether the proposed platform provides additional benefits over traditional coding assessment systems.
* **User Evaluation** – to assess student satisfaction, usability, understanding, and usefulness of the feedback.

The solution will be considered successful if it demonstrates **reliable automated assessment, useful AI-generated feedback, effective identification of coding skills, and improved learning support**, while satisfying the defined requirements for performance, efficiency, reliability, and usability.
